# 授權與出處

## Microsoft Fluent Emoji

水簾洞 37 音卡片圖（`img/cards/<注音>.png`）主要以 [Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji) 的 **3D** 圖庫為來源，再裁切、縮放並置中到 512×512 透明畫布。

- 授權：MIT License
- 著作權：Copyright (c) Microsoft Corporation
- 專案：https://github.com/microsoft/fluentui-emoji
- 原始圖路徑形式：`assets/<名稱>/3D/<名稱>_3d.png`（有膚色的符號使用 `Default` 子資料夾，例如 `Ear/Default/3D/ear_3d_default.png`）

未改 Fluent Emoji 的授權條款。完整授權文字見上游倉庫的 [LICENSE](https://github.com/microsoft/fluentui-emoji/blob/main/LICENSE)。

有兩張目前沒有適合的圖庫圖，本版先不放檔案、遊戲會用表情符號暫代，之後由毛毛繪製：

- `ㄓ` 蜘蛛：Fluent 3D 蜘蛛偏寫實、對五歲偏可怕
- `ㄢ` 安全帽：圖庫沒有黃色工程安全帽（只有紅色救護帽與綠色軍用頭盔）

對應關係與替代說明見 `design/cards-art.md`。毛毛先前所繪的 3 張樣本（葡萄、蜘蛛、耳朵）這一版先不用。
